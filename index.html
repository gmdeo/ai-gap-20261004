The Problem: AI "Goldfish Memory"

AI assistants lose context mid-conversation, forget important instructions, and mix up details from different exchanges. Users lose 11-20% of work time constantly repeating themselves.

"It seems to have a goldfish memory now, even if it has access to the written information, it will ignore a lot of it so you constantly need to repeat stuff"
"I wish every instruction and response had a enable/disable checkbox so that I can disable parts of the conversation"

Over 50 mentions across Reddit and Hacker News with users using consistent frustrated language: "goldfish memory", "constantly repeat", "doesn't remember anything"

How Context Craft Works

✅

Toggle Context

See every message in your conversation. Toggle individual messages on or off to control what the AI remembers.

📦

Archive Old Messages

Move outdated code, rejected ideas, or obsolete instructions out of active context. Keep them for reference without polluting current work.

📊

Token Visibility

See estimated token count for your active context. Understand capacity constraints instead of hitting mysterious limits.

🔄

Reversible Changes

Archive is reversible, not permanent deletion. Experiment with different context combinations without fear of data loss.

Example Workflow

Step 1: You're working on a coding project

After 20 exchanges, you've fixed bugs and improved the design. But the conversation now contains early broken code and outdated ideas.

Step 2: Without Context Craft

Claude starts suggesting the old broken approach because it's still in context. You have to repeatedly say "no, we already fixed that" or start fresh (losing all good context).

Step 3: With Context Craft

Open the sidebar. Toggle OFF messages with old code and outdated ideas. Next response reflects only the curated context — AI remembers exactly what you want it to remember.

Research-Backed Design

  • Memory Hierarchy: Active context (L1 cache) + Archive (L3 storage) prevents context pollution
  • User Control: Manual curation creates engagement — users report "finally!" response when given memory management
  • Trust Restoration: 41% of users report repeating information to AI; explicit toggle action rebuilds confidence
  • Cognitive Load Reduction: Reversible archive reduces loss anxiety; immediate visual feedback on every toggle
  • Accessibility: Keyboard navigation, WCAG AA contrast, reduced-motion support
